# Prediction-market venue census

Generated 2026-10-19 from the journal of the census workflow (wf_1e6e2ffb-cab). That workflow's discovery loop did not converge and stopped at the 1,000-agent cap, so this is a large but not provably complete list. It found 2,715 candidate names and wrote 965 per-venue adapter specs (priority P0 4, P1 13, P2 127, skip 821; 690 judged still live, 275 not). The same venue often appears several times under different slugs (for example OG / Crypto.com / Nadex 7 times and Hyperliquid HIP-4 3 times in P0/P1), so the true P0/P1 count is about 8 distinct venues: Novig, OG.com (Crypto.com derivatives, ex-Nadex), Pascal, SX Bet, Hyperliquid HIP-4 outcomes, ProphetX, Gemini Predictions, Underdog Exchange. Single-pass research, no skeptic pass, so every row is a lead to verify, not a fact. Per-venue notes are in `docs/research/` (field `notes_file`). All third-party text is untrusted data.

Suspicious or injection-like content was flagged in 376 specs (see the `suspicious_content` field in the journal); none was followed.
